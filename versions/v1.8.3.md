## 改了什么

1. 新增 134 条 emoji 中文名、116 条线性图标中文名、28 个颜色中文名（如蓝 / 玫红 / 深青）。
2. 悬停 emoji 图标 → 显示中文（`🛒` 显示「购物车」）；悬停线性图标 → 同样中文（不再是 `shopping-cart`）。
3. 色板悬停显示颜色名，不再显示 `#1F6FEB` 这种色值。
4. 分类行左侧的图标按钮显示「选择图标 · 购物车」——既说动作也说当前是什么图标。
5. 查不到名字时退回原值，不会显示空白。
