## 这一版做了什么

原来只有 12 个图标，分类多了不够用。现在：

1. **约 120 个图标**（8 组 × 12–16 个），全部是 Unicode emoji——不用打包任何图片、没有版权问题、在 Windows/macOS/Linux 上都能显示。
2. **按用途分组**：常用 / 文档 / 数据 / 技术 / 媒体 / 工作 / 生活 / 标记，每组左边有名字，找起来不用横向扫。
3. **面板可滚动**：图标多了以后面板最高 230px（跟着界面大小缩放），超出就滚，不会把下面的分类挤出屏幕。
4. **老图标不动**：原来 12 个都还在「常用」组里，已经用的分类照旧显示。
5. 清除（∅）保留在最后一行。

## 使用方式

分类行点 `🎨` → 面板展开 → 左侧选组、右侧点图标，点完自动收起。想清掉图标点最后的 ∅。

## 数据结构变化

无。图标还是 `folders[].icon` 里的一个字符串。

## 已知限制

- 图标只有 emoji，没有单色矢量图标；如果以后想要 Lucide / Tabler 这类开源线性图标，需要改成内联 SVG 渲染，是另一版的工作。
- 图标面板没有搜索框，靠分组找；120 个里找常用的应该够。
