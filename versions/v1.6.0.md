## 用法

1. 主面板工具栏点 **「固定到右侧」** → 右侧栏出现「工作区管理」标签页。
2. 标签页顶部一行：**项目下拉 + 待归类(n) + 归档(n) + 展开到主面板**，下面是该项目的分类树和对话。
3. 点对话就地打开，右侧面板**不动**；想回大页点「展开到主面板」。

## 说明

1. 右侧栏是 DSH 自带的标签页系统，和「项目文件坞」同一个位置，两边可以并存切换。
2. 右侧栏版是紧凑布局：没有左栏、没有缩放三档、没有批量条以外的按钮，避免挤。
3. 分类树、拖拽归类、`🎨` 图标这些在右侧栏里一样能用。
4. 主面板照旧保留，两处共用同一份数据（切项目会同步）。
