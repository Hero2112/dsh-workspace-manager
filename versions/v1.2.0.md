## 这一版做了什么

- 新增**分类管理视图**：工具栏「管理分类」一键把当前项目的所有分类变成平铺表格，层级用缩进表示，操作按钮常驻显示（不用悬停找按钮）。
- 新增**改上级**：每行一个「上级」下拉，选谁就成为谁的子分类，选「顶层」回根目录；下拉里自动排除自己和自己的子分类，**结构性杜绝循环引用**。
- 新增**合并分类**：点 `⤵` 选目标，源分类连同子分类一起删除，其中的对话**全部转入目标分类**，一个不丢。
- 新增**清理空分类**：一次删掉所有没有任何对话的分类（含嵌套子分类），适合分类建多了之后收尾。
- 新增**管理视图内的重命名 / 调序 / 置顶 / 改色 / 改图标 / 新建子分类 / 删除**，全部在行内完成，行为与树视图一致。
- 新增**分类名搜索**：管理视图里顶部搜索框照常按分类名过滤。
- 改进**撤销体系**：合并、清理空分类也纳入撤销条（12 秒），提示文案按操作类型区分（`已合并到「X」` / `已清理 N 个空分类`），不再是统一的"已删除文件夹"。
- 改进**键盘**：管理视图里 `Enter` / `F2` 直接进入改名，与树视图一致。
- 改进**代码可读性**：全部注释改为中文（`client.js` 的分区标题、函数说明、行内说明，`index.js` 文件头），代码标识符仍为英文。只动注释、行为零变化，冒烟测试重跑 39 项全过。

> 说明：1.2.0 在首次对外提交（GitHub 公开仓库）之前做过一次注释中文化，版本号未变；`releases/v1.2.0/` 与 `dist/workspace-manager-1.2.0.zip` 都是中文化之后的最终产物，本文档记录的哈希即对应这一版。

## 使用方式

入口不变：左侧边栏第三个图标（橙色文件夹）→ 主区域 → 工具栏点 **「管理分类」**。

| 想做什么 | 怎么做 |
|---|---|
| 给分类改名 | 点分类名 → 输入 → 「确定」；或选中行按 `Enter` / `F2` |
| 把分类挪到另一个分类下 | 行内「上级」下拉 → 选目标分类 |
| 把分类挪回根目录 | 行内「上级」下拉 → 选「顶层」 |
| 调整同级顺序 | 行内 `▲` / `▼` |
| 置顶常用分类 | 行内 `📍`（变成 `📌`） |
| 合并两个分类 | 目标行点 `⤵` → 「合并到…」下拉选目标 → 源分类消失，对话全部归入目标 |
| 一次删掉所有空分类 | 工具栏「清理空分类」（12 秒内可撤销） |
| 删掉某个分类 | 行内 `×`，**点两次**确认（12 秒内可撤销） |
| 回到原来的对话视图 | 工具栏「回到对话」 |

## 数据结构变化

存储键不变：仍是 `dsh.workspace-manager.v2`。

| 字段 | 变化 | 兼容处理 |
|---|---|---|
| `prefs.manage` | 新增，布尔，记录是否停在分类管理视图 | `normalizePrefs` 缺字段一律按 `false`，v1/v2 旧数据都不需要迁移 |
| `folders[]` | 结构不变（`id/name/parentId/color/icon/pinned`），顺序即同级顺序 | 合并/删除只做删项与改 `parentId`，不改结构 |

v1 旧存储键 `dsh.workspace-manager.v1` 的自动迁移逻辑未受影响（回归测试覆盖）。

## 已知限制

- 管理视图是**按项目**管理的：一次只显示当前项目的分类。跨项目总览还没做。
- 管理视图里不支持拖拽（树视图支持）：管理视图用显式控件完成同样的操作，避免两套拖拽语义互相干扰。
- 合并、清理、删除都只作用于**当前项目**的分类。
- 分类总数达到几百时，表格仍是平铺渲染（无虚拟滚动），可能有轻微滚动卡顿。
