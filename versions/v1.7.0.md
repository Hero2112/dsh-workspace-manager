## 说明

1. **线性图标 76 个**，分四组：电商·线（购物车/店铺/包裹/标签/支付/钱包/物流/单据/优惠券…）、新媒体·线（喇叭/场记板/摄像机/胶片/剪辑/图片/音乐/电台/私信/点赞/磁铁/靶心…）、运营客服·线（耳机/救生圈/退货/勾选清单/日历/时钟/分享/艾特/话题/播放/投屏/用户…）、通用·线（文件夹/文档/星标/火焰/对勾/警告/信息/书签/灯泡/火箭/饼图/搜索/筛选/图层/链接/上传/下载/闪光/盾牌）。
2. 线性图标来自 [Lucide](https://github.com/lucide-icons/lucide)（lucide-static 0.460.0，ISC 许可），**内联成 SVG path**，不加载外部文件、不用联网。
3. 存法：`folder.icon` 里写 `svg:<name>`；老的 emoji 原样保留，两种可以混着用。
4. 面板上半 emoji、下半线性图标，都按业务分组，选中态分别是描边高亮。
5. 之前那两组电商/新媒体 emoji 保留。
