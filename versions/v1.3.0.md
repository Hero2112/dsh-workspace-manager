## 这一版做了什么

- 新增**界面大小三档**（小 / 中 / 大），工具栏最右侧下拉切换。改的是一个整体缩放系数 `--wm-k`，所以**字号、行高、按钮、图标、间距一起缩放**，不是只放大文字。三档实测：正文 11.7 / 14 / 17.9px，按钮高 24 / 29 / 37px，行高 27 / 32 / 41px。
- 改进**默认尺寸**：中档正文从 1.2.0 的 13px 提到 14px——原来那个尺寸在高分屏上确实偏小。
- 新增**左栏可拖拽**：左栏与主区域之间的竖线可以左右拖，范围 170–620px（按当前缩放折算），双击复位，也可以先点竖线再按 `←` `→` 微调、`Home` 复位。
- 新增**宽度记忆**：拖好的宽度记进 `prefs.navWidth`，刷新、重启、切项目都保持。
- 改进**项目名可确认**：左栏项目按钮的悬停提示改为「项目全名 + 磁盘路径」，左栏再窄也能确认是哪个项目。
- 改进**拖拽手感**：拖动时用指针捕获（pointer capture），鼠标滑出竖线也不会断；拖动过程只更新预览，松手才写存储，避免拖一次写几十次 localStorage。

## 使用方式

| 想做什么 | 怎么做 |
|---|---|
| 整体变大 / 变小 | 工具栏最右侧「界面大小」下拉 → 小 / 中 / 大 |
| 把左栏拉宽看清项目全名 | 鼠标移到左栏右边的竖线上（光标变成 ↔）→ 按住左右拖 |
| 恢复默认宽度 | 双击那条竖线 |
| 用键盘调宽度 | 先点一下竖线让它获得焦点 → `←` `→` 每次一级 → `Home` 复位 |
| 看某个项目的完整名字 | 鼠标停在该项目上，提示里同时给出全名和磁盘路径 |

## 数据结构变化

存储键不变：仍是 `dsh.workspace-manager.v2`。

| 字段 | 变化 | 兼容处理 |
|---|---|---|
| `prefs.scale` | 新增，`'sm'` / `'md'` / `'lg'`，默认 `'md'` | `normalizeScale` 只认这三个值，其它一律回落到 `'md'` |
| `prefs.navWidth` | 新增，数字，左栏**基准**宽度（未乘缩放系数），默认 224 | `clampNavWidth` 限制在 170–620，非数字回落到 224 |
| `folders[]` / `assignments` | 无变化 | — |

## 已知限制

- 三档是离散的，没有连续滑块（想再细调还是得靠浏览器缩放）。
- 缩放只作用于本插件面板，不影响 DSH 其它界面。
- 「大」档下工具栏按钮较多，窄窗口时可能换行（工具栏本来就是 `flex-wrap: wrap`）。
- 左栏宽度按缩放系数折算，所以从中档切到大档时，视觉上会更宽；反切会变窄。
