## 这一版做了什么

**根因**：主按钮（「管理分类」「新建文件夹」）和界面大小选中档用的是「品牌色底 + 白字」。而 DSH 的**暗色主题里品牌色本身就是近白色**（`--dsw-alias-brand-primary` = `#f9fafb`），于是白字压白底，实测对比度只有 **1.05:1** —— 不是"偏淡"，是彻底看不见。浅色主题里品牌色是近黑色（`#0f1115`），白字 18.9:1，所以只在暗色下暴露。

修复与改进：

- **主按钮 / 危险按钮 / 界面大小选中档**：从「实色底 + 白字」改成「品牌色淡底 + 品牌色文字 + 品牌色描边」。暗色 9.1:1、浅色 13.4:1，两种主题都清楚。
- **删除类按钮**：危险色直接当文字只有 3.4:1，改成「危险色 70% + 主文字色 30%」——浅色下混黑更深、暗色下混白更亮，两边都到 5.5:1 左右。
- **hover / 选中 / 表头 / 徽标**：浅色主题里 `bg-layer-1` 与 `bg-layer-2` **都是 `#fff`**，所以以前用它们做 hover 完全没反馈。现在统一改成「主文字色 × 9%」的 tint，浅色暗色都看得见。
- **次要文字**：从主题 secondary 改成「主文字色 × 74%」，浅色 8.2:1、暗色 8.8:1，比原来更稳。
- **提示条 / 撤销条**：正文改用主文字色（浅色 16.7:1、暗色 11.1:1），警告色只保留边框和底色——原来拿 `amber-500` 当文字压在浅色淡底上只有约 2:1。
- **下拉框文字**：改用主文字色；**原生 `<option>` 列表**也配上 `--wm-surface` / `--wm-text`，否则暗色下会冒出白底黑字。
- **键盘焦点**：所有可交互元素统一 2px 品牌色焦点环（`focus-visible`），暗色下也能看见。
- **架构**：所有颜色收进一层语义变量（`--wm-surface` / `--wm-text(-dim)` / `--wm-line(-2)` / `--wm-accent(-soft/-line)` / `--wm-danger(-soft/-line/-text)` / `--wm-warn(-soft)` / `--wm-hover(-2)`），组件只引用语义变量。**CSS 里不再有写死的颜色**，token 缺失时也有中性灰兜底。

## 使用方式

功能、入口、快捷键与 1.3.1 完全一样，不需要学新操作。切到暗色主题后：

| 位置 | 现在 |
|---|---|
| 「管理分类」「新建文件夹」按钮 | 淡底 + 品牌色文字，清楚可读 |
| 界面大小当前档 | 同上，不再是白底白字 |
| 鼠标移到对话行 / 左栏项目 | 有明显的底色变化（以前在浅色下没反应） |
| 提示条 / 撤销条 | 正文用正常文字色，边框是警告色 |
| 删除确认按钮 | 红字（混合后更深/更亮），看得清 |
| 下拉框展开后的列表 | 跟随主题，不再白底 |

## 已知限制

- 跟随的是 DSH 主题 token，**不跟随系统深色模式**（插件自己没有主题开关，这是设计上的选择：跟宿主一致）。
- 如果你装了第三方主题并把 `--dsw-alias-*` 改成低对比的取值，插件的对比度只能保证不低于主题本身的水平——这时需要调主题，不是调插件。
- 文件夹彩色圆点仍是固定的 7 色调色板（装饰用途，不参与文字对比度）。
