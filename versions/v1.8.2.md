## 改了什么

1. 分类行动作顺序固定为「查看 / ▲ / ▼ / ＋ / 🎨 / 📍 / ⤵」→ **竖分隔线** → 「×」删除，删除永远在最右。
2. 删除按钮**常态红色**（`wm-ghost-danger` 直接上红字），悬停时红底，不再只靠悬停区分。
3. 批量操作条：「批量归类」「取消选择」之后加分隔线，再放「归档」，避免顺手点到。
4. 分隔线宽 1px、颜色走主题变量，暗色浅色都清楚；随界面大小缩放高度。
