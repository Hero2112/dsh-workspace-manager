## 这一版做了什么

**改一处命名**：左栏第一项 `收件箱` → **`待归类`**（英文 `Inbox` → `To sort`）。

为什么原来的名字不对：

1. **收件箱的含义是"新进来的东西"**——邮件收件箱里放的是别人刚发给你、你还没读的消息。而这一栏装的是**跨所有项目、还没归入任何分类的对话**，其中绝大多数是很久以前的老对话，不是"新收到的"。
2. **和插件自己的另一处说法打架**：项目内部那个没归类的分区叫「未分类」，同一个概念在左栏叫「收件箱」，看的人要多想一步它们是不是两回事。
3. 这个插件做的事情是"整理"，不是"收发"。左栏是**待办视角**，不是消息容器。

新名字的理由：

- 「待归类」同时表达**状态**（还没进任何分类）和**动作**（该整理了），用户一眼知道点进去要干什么；
- 和紧邻的「归档区」形成对称（都是 3 个字、都是"把对话归位"的视角）；
- 和项目内部的「未分类」区分清楚：`未分类` 是项目里的一个分区，`待归类` 是跨项目的汇总视图。

配套改动：

## 使用方式

功能和位置都没变：左栏从上到下是「搜索 → 添加项目 → **待归类 (n)** → 归档区 (n) → 项目列表」。点「待归类」还是看到跨项目的未归类对话汇总，带项目标签，可就地归类。

## 数据结构变化

无。`localStorage` 字段完全不变，视图标识仍然是 `unfiled`（所以升级后仍停在你原来那个视图上）。
