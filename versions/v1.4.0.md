## 这一版做了什么

**问题**：对话视图里分类是展开的、对话就在分类行下面，但**分类管理视图只列分类、看不到里面的对话**，你从那边找不到"这个分类里到底有哪些对话"的入口。

改动：

1. **分类管理表里每行加「查看」**：点它跳回对话视图，自动展开该分类的所有上级，并选中落在它那一行（滚到视野中间）。
2. **数字徽标变成可点**：分类管理里点那个对话数 = 同上；对话视图里点它 = 收起/展开这个分类。
3. **点分类名也能收起/展开**：以前分类名是纯文字，现在点它就能收放，符合"点文件夹看里面"的直觉。
4. **提示语补一句**：分类管理页顶部的说明加了"点「查看」看分类里的对话"。

## 使用方式

| 想看分类里的对话 | 怎么做 |
|---|---|
| 已经在对话视图 | 分类行下面直接列着它的对话，点分类名或右边数字可收起/展开 |
| 在分类管理视图 | 点行内「查看」，或点那个数字徽标 |
| 用键盘 | 选中分类行按 `Enter` 也能展开/收起 |

## 数据结构变化

无。`localStorage` 字段不变；新增的只是一个界面状态（选中哪一行、是否展开），不落盘。

## 已知限制

- 跳转只滚动、不改变排序或筛选，所以分类在很长列表里仍然靠"选中高亮"标识。
