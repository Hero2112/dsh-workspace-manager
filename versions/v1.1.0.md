## 这一版做了什么

### 1. 双栏布局
单列卡片换成左导航 + 右内容：左栏（宽 224px）是「搜索 / 添加项目 / 收件箱 / 归档区 / 项目列表」，右栏是当前视图的对话与文件夹。项目再多也不用来回长滚动。

### 2. 拖拽归类
- 对话行拖到文件夹行 → 归入该文件夹
- 对话行拖到「未分类」标题行 → 移出文件夹
- 文件夹拖到文件夹 → 变成它的子文件夹（**拦住拖进自己子孙**的循环）
- 文件夹拖到「未分类」标题行 → 回到根层
- 拖拽时目标行高亮，松手即生效；下拉框归类作为备用入口保留

### 3. 批量操作
每行左侧复选框。勾选后底部出现操作条：`已选 N` + 「批量归类到▾」+「取消选择」，最后端才是「归档」（与下拉框隔开，防误触）。归档区里则是「批量恢复」。

### 4. 文件夹配色与图标
- 行首圆点点击循环 7 色调色板
- `🎨` 展开 12 个 emoji 图标选择器，∅ 清除
- 颜色和图标都是纯装饰数据，只存在本地

### 5. 未分类收件箱
左栏「收件箱」汇总**所有项目**的未归类对话，每行带项目标签，可就地归类，不用先进项目再找。

### 6. 归档区（新增，可恢复）
左栏「归档区」列出所有已归档对话，支持单个「恢复」与批量恢复。

### 7. 置顶、同级排序、排序方式
- `📍/📌` 文件夹置顶，同层置顶优先显示
- `▲▼` 调整同级顺序
- 工具栏「排序」：最近活动 / 按名称 / 按创建时间，选择持久化

### 8. 撤销删除
删除文件夹后，提示条保留 12 秒，点「撤销」或按 `Ctrl+Z`，**文件夹、子文件夹、以及其中的归类关系**整体复原。

### 9. 键盘操作
| 键 | 作用 |
|---|---|
| `Ctrl+K` | 聚焦搜索框 |
| `↑` `↓` | 在可见行之间移动焦点 |
| `Enter` | 打开对话 / 展开文件夹 / 恢复归档对话 |
| `←` `→` | 收起 / 展开文件夹 |
| `F2` | 重命名选中的文件夹 |
| `Esc` | 清空搜索；无搜索时取消多选 |
| `Ctrl+Z` | 撤销删除 |

### 10. 安全改造：「打开」与「归档」不再相邻
这是用户明确提出的风险点：原来行尾并排两个按钮，想点「打开」可能点到「归档」。

现在：
- **打开** = 点击行内**标题文字本身**（悬停出现下划线），或选中后按 `Enter`
- **归档** = 行最右侧 `⋯` 菜单 → 展开一条独立操作条 → 点「归档」变红为「确认归档」→ **再点一次**才生效（5 秒内有效，旁边永远有「关闭」）
- 行内不再存在任何打开/归档并排按钮

并明确：**归档不是删除**。会话记录与磁盘日志都保留，误归档有三条恢复路径：归档区单个恢复、归档区批量恢复、原生侧边栏归档列表。

## 使用方式

| 操作 | 怎么做 |
|---|---|
| 打开面板 | 侧边栏第三个图标（橙色双层文件夹） |
| 切换项目 | 左栏点项目名 |
| 归类对话 | 拖到文件夹行，或用行内下拉框 |
| 批量归类 | 勾选多个 → 底部「批量归类到▾」 |
| 归档对话 | 行尾 `⋯` → 「归档」→ 「确认归档」 |
| 恢复归档 | 左栏「归档区」→ 「恢复」 |
| 调整文件夹 | 行内 `▲▼＋🎨✎📌◆×`（上移/下移/子文件夹/图标/重命名/置顶/新建对话/删除） |
| 撤销删除文件夹 | 提示条「撤销」或 `Ctrl+Z` |
| 回对话界面 | 右上角「返回对话」 |

## 数据结构变化

存储键升级为 `dsh.workspace-manager.v2`：

```js
{
  version: 2,
  projects: {
    "<workspaceId>": {
      folders: [{ id, name, parentId, color, icon, pinned }],  // 新增 color/icon/pinned
      assignments: { "<sessionId>": "<folderId>" }
    }
  },
  prefs: { sort: 'recent'|'title'|'created', activeKind: 'project'|'unfiled'|'archived', activeProjectId }
}
```

`readStore()` 在 v2 键不存在时读取 `dsh.workspace-manager.v1` 并补齐新字段（`normalizeFolder` / `normalizePrefs`），损坏的 JSON 会回落到空结构而不是崩溃。

## 已知限制

- 未分类收件箱里的批量「归类到」只能选**当前项目**的文件夹，跨项目归类请进对应项目操作（避免把 A 项目的对话塞进 B 项目的文件夹 id）
- 拖拽依赖 HTML5 drag & drop，触屏设备上不可用（下拉框是替代路径）
- 文件夹树没有移动端折叠优化，层级很深时需要横向空间
- 数据只在本浏览器：换电脑或换浏览器需要重新归类（对话本身不受影响）
- 归档区显示的标题依赖 session 快照，快照尚未加载到该会话时只显示 id 前 8 位
