## 这一版做了什么

- 新增侧边栏入口图标（在「插件」「定时任务」之后），点击打开独立的管理页
- 把每个 **项目（= DSH 工作区）** 作为一个卡片展示，卡片内是该项目的文件夹树
- **文件夹树**：支持多级子文件夹、展开 / 收起
- **对话归类**：每个对话行带一个下拉框，选文件夹即归类，选「未分类」即移出
- **未归类区**：每个项目顶部的落地区，显示不属于任何文件夹的对话
- **新建文件夹 / 新建子文件夹 / 重命名 / 删除**
  - 删除需要**点两次**（第一次变成「再点一次确认删除」），5 秒后自动复原
  - 删除文件夹会连同子文件夹一起删除，里面的对话退回「未分类」，**不删除对话本身**
- **打开对话 / 归档对话**（行尾两个按钮）
- **新建对话**：工具栏可在项目根目录建，文件夹行内也可建，建完自动归入该文件夹
- **搜索框**：按对话标题、文件夹名过滤
- 中英文文案、文件夹与归类数据存浏览器 `localStorage`（键 `dsh.workspace-manager.v1`）

## 使用方式

| 操作 | 怎么做 |
|---|---|
| 打开管理页 | 侧边栏面板图标区，第三个文件夹图标 |
| 建文件夹 | 工具栏「新建文件夹」，或在文件夹行点「＋」建子文件夹 |
| 归类一个对话 | 对话行右侧下拉框选文件夹 |
| 找对话 | 顶部搜索框输入标题片段 |
| 回对话界面 | 页面右上角「返回对话」 |

## 数据结构

```js
// localStorage: dsh.workspace-manager.v1
{
  version: 1,
  projects: {
    "<workspaceId>": {
      folders: [{ id, name, parentId }],   // parentId 为 null 表示根层
      assignments: { "<sessionId>": "<folderId>" }
    }
  }
}
```

## 已知限制（驱动 1.1.0 改造）

- 单列卡片 + 长滚动，项目一多就要翻很久
- 只能靠下拉框归类，不能拖拽
- 无法批量处理，只能一个个改
- 删除文件夹不可撤销
- **「打开」与「归档」两个按钮相邻**，误点归档的风险高
- 没有置顶、排序、颜色、图标；归档后无法在面板内恢复
