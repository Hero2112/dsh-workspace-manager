# v1.6.4 — 分类条整条染色

**一句话**：每个分类条左边那个圆点现在是**取色入口**，选好颜色后整条分类条都会染上该色，并带一条左侧色带。

## 说明

1. 点圆点 → 弹出 8 个选项（7 种颜色 + ∅ 清除），选一个立刻生效。
2. 整条分类条底色 = 该颜色 18% 混合，左侧 3px 色带；分类名文字不变色，保证可读。
3. 管理分类表里的分类行同样整条染色。
4. 旧行为（点一下轮换下一个颜色）改成「点一下开色板」，选得更准。
5. 折叠起来的子分类不显示，展开后照样有颜色。
