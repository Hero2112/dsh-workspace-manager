# 工作区管理（Workspace Manager）v2

DeepSeek Harness Web UI 插件：把每个 **项目（= Harness 工作区）** 下的 **对话** 整理进自己建的文件夹。

## 打开方式

左侧边栏底部的面板图标区，点击橙色的文件夹图标（「插件」「定时任务」之后第三个）→ 主区域打开管理页。

## 界面

```
┌ 左侧导航 ──────────┬ 主区域 ────────────────────────────────────┐
│ 搜索（Ctrl+K）      │ 标题 / 路径            [返回对话]           │
│ ＋ 添加项目         │ [管理分类][新建文件夹][新建对话][排序▾] [中▾] │
│ 收件箱 (n)          │ ⚠ 提示条 / 撤销条                           │
│ 归档区 (n)          │ ☑ 已选 n [批量归类到▾][归档][取消]          │
│ 项目 A (12)         │ ┌ 未分类 (3) ────────── 拖到这里归类 ┐      │
│ 项目 B (7)          │ │ ☑ ›对话标题‹      11-03 ▾ ⋯        │      │
│                     │ │ ▾ ● 📁 素材 (2)  ▲▼＋🎨✎📌◆×       │      │
│                     │ │    ☑ 子对话…                        │      │
└─────────────────────┴────────────────────────────────────────────┘
                        ↑ 这条竖线可以左右拖
```

工具栏右侧的 `[中▾]` 是**界面大小**（小 / 中 / 大，见下）；左栏与主区域之间那条竖线可以**左右拖动**，把左栏拉宽就能看清项目全名。

点「管理分类」后主区域换成**分类管理表**（同一批分类，一行一个，操作按钮常驻）：

```
分类                    对话   上级            操作
● 📝 论文二            2     [顶层 ▾]        ▲▼＋🎨📌⤵×
  ● 📁 数据            1     [论文二 ▾]      ▲▼＋🎨📌⤵×
● 🎬 素材              0     [顶层 ▾]        ▲▼＋🎨📌⤵×
```

## 能力

### 对话视图（1.1.0）

| # | 能力 | 用法 |
|---|---|---|
| 1 | 拖拽归类 | 拖对话行到文件夹行 = 归入该文件夹；拖到「未分类」标题行 = 移出文件夹；拖文件夹到文件夹 = 变成子文件夹；拖文件夹到「未分类」= 移回根目录（禁止拖进自己的子级） |
| 2 | 批量操作 | 勾选多个对话 → 底部条出现，可「批量归类到」某文件夹 / 批量归档；归档区里可批量恢复 |
| 3 | 文件夹图标与颜色 | 每行左侧圆点点击 = 切换 7 色调色板；`🎨` = 选图标（12 个 emoji，∅ 清除） |
| 4 | 未分类收件箱 | 左栏「收件箱」= 跨所有项目的未归类对话汇总，带项目标签，可就地归类 |
| 5 | 归档区 | 左栏「归档区」= 所有已归档对话，支持单个/批量「恢复」 |
| 6 | 置顶与排序 | 文件夹 `📍/📌` 置顶（同层置顶优先显示）；`▲▼` 调整同级顺序；工具栏「排序」= 最近活动 / 按名称 / 按创建时间 |
| 7 | 撤销删除 | 删除文件夹后 12 秒内点提示条「撤销」或按 **Ctrl+Z**，文件夹、子文件夹与其中的归类全部复原 |
| 8 | 双栏布局 | 左导航（项目 / 收件箱 / 归档）+ 右内容区，项目再多也不用长滚动 |
| 9 | 快捷键 | `Ctrl+K` 聚焦搜索；`↑↓` 移动焦点；`Enter` 打开对话 / 展开文件夹；`←→` 收起 / 展开；`F2` 重命名选中文件夹；`Esc` 清搜索或取消多选；`Ctrl+Z` 撤销删除 |
### 分类管理（1.2.0）

分类一多，在树视图里逐行找按钮就慢了。点工具栏 **「管理分类」**，同一个项目的所有分类变成一张平铺表格：**层级用缩进表示，操作按钮常驻可见**，不用悬停去找。

| 操作 | 怎么做 |
|---|---|
| 改名 | 点分类名（或选中行按 `Enter` / `F2`）→ 就地输入 → 「确定」 |
| 换上级 | 行内「上级」下拉：选另一个分类 = 变成它的子分类；选「顶层」= 移回根目录。**下拉里不会出现它自己和它的子分类**，从根上杜绝循环引用 |
| 调顺序 | 行内 `▲` / `▼` 与同级分类交换位置 |
| 置顶 | `📍` → `📌`，同级里置顶的排在前面 |
| 改颜色 / 图标 | 左侧圆点循环换色；`🎨` 打开 12 个 emoji 图标面板 |
| 新建子分类 | 行内 `＋` |
| 合并分类 | 点 `⤵` → 该行出现「合并到…」下拉 → 选目标：源分类及其子分类一起删掉，**里面的对话全部转到目标分类**，一个都不丢 |
| 删除分类 | 行内 `×`，**点两次确认**，12 秒内可撤销 |
| 清理空分类 | 工具栏「清理空分类」：一次删掉所有没有任何对话的分类（含子分类），12 秒内可撤销 |
| 回到对话视图 | 工具栏「回到对话」 |
| 搜分类 | 顶部搜索框在管理视图里同样按分类名过滤 |

安全设计：合并禁止指向自己或自己的子分类；改上级同样做祖先检查；删除、合并、清理都可撤销，而且**任何分类操作都不删除对话**，只改归类关系。

### 界面大小与分栏宽度（1.3.0）

高分屏上默认字号偏小时，不用去改浏览器缩放——插件自带三档界面大小：

| 档位 | 正文 | 按钮高 | 行高 | 适合 |
|---|---|---|---|---|
| 小 | 11.7px | 24px | 27px | 想一屏塞下更多行 |
| **中（默认）** | **14px** | **29px** | **32px** | 日常使用，比 1.2.0 的 13px 略大 |
| 大 | 17.9px | 37px | 41px | 高分屏 / 离屏幕远 |

位置：工具栏最右侧的「界面大小」下拉（选项就是 小 / 中 / 大）。改的是整体缩放系数，所以**字号、行高、按钮、图标、间距一起变**，不是只放大字。选择记在浏览器里，刷新和重启都保留。

左栏宽度可以拖：

| 操作 | 怎么做 |
|---|---|
| 调宽 / 调窄 | 鼠标移到左栏右边那条竖线上（光标变成 ↔），按住左右拖 |
| 复位 | 双击那条竖线，回到默认宽度 |
| 用键盘调 | 先点竖线让它获得焦点，再按 `←` `→` 每次一级，`Home` 复位 |
| 看全名 | 左栏再窄也没关系——鼠标悬停项目名会显示**全名 + 磁盘路径** |

宽度范围 170–620px（按当前缩放折算），拖到哪就记到哪，下次打开还是这个宽度。

## 「打开」与「归档」为什么分开

打开是高频、安全的动作；归档是低频、改变列表的动作。把两者并排做成一排按钮，误点代价不小，所以拆成了两种完全不同的交互：

| 动作 | 位置 | 交互 |
|---|---|---|
| **打开对话** | 行内**标题文字**（悬停有下划线） | 单击标题即打开；或选中后按 `Enter` |
| **归档** | 行最右侧 `⋯` | 点开后才展开一条独立操作条，且要点**两次**（归档 → 确认归档，5 秒内有效），旁边永远有「关闭」 |

**归档不会丢东西**：会话记录与磁盘上的会话日志都保留，只是移出普通列表。误归档后有三种恢复路径：

1. 左栏「归档区」→ 找到它 → 点「恢复」；
2. 「归档区」里勾选多个 → 批量「恢复」；
3. 原生侧边栏的归档会话列表同样可以恢复。

真正不可逆的只有「删除文件夹」，那个有 12 秒撤销（提示条按钮或 `Ctrl+Z`），且不会删除任何对话。

## 数据存放

- 文件夹树、归类关系、视图偏好：浏览器 `localStorage` 的 `dsh.workspace-manager.v2`（v1 数据会自动迁移）。
- 视图偏好里的界面数据：`manage`（是否停在分类管理视图）、`scale`（`sm` / `md` / `lg`）、`navWidth`（左栏基准宽度，未乘缩放系数）。这几个字段缺了都按默认值处理，所以旧数据不需要迁移。
- 工作区与对话本身：Host 权威数据，通过实时服务快照读取，所有写操作走官方 Workspace 服务（新建/归档/恢复/打开会话）。
- **不改动磁盘文件**。清空浏览器存储 = 回到没有任何文件夹的状态；对话本身不受影响。

## 开发

- **注释一律用中文**（2026-11-04 起）：代码标识符保持英文，`//` 与 `/** */` 里的说明、分区标题全部写中文，方便直接读仓库。
- **尺寸必须写 `calc(Npx * var(--wm-k))`**（1.3.0 起）：`--wm-k` 是界面缩放系数，不乘它的固定像素在「大」档下不会跟着变。只有 `.5px` 边框、焦点环这类线条粗细故意保持固定。改完可以跑一遍静态检查，确认没有漏网的 `px`。
- 纯 Client 半实现，无构建步骤：`client.js` 用 `window.__ModuleLoader__.load` 注册，`index.js` 是空的 Host 半。
- 源码公开在 GitHub：[Hero2112/dsh-workspace-manager](https://github.com/Hero2112/dsh-workspace-manager)。
- 只往官方插槽里**新增**条目：`sidebar.panellist`（入口图标）+ `main`（面板，key 与图标 id 相同）。
- 样式只用主题 token（`--dsw-alias-*`），文件夹颜色为数据驱动的装饰色。
- 改完 `client.js` 后：先刷新页面；若界面仍是旧版，需完全退出并重启 DSH 以加载新的客户端模块代次。
- **换安装路径（例如 `releases/v1.1.0` → `releases/v1.2.0`）必须完全重启 DSH**：客户端模块按代次缓存，路径一变旧代次不会自动重建，表现是图标与面板凭空消失。
