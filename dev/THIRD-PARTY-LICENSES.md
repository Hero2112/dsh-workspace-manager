# 第三方资源与许可证

本插件内联了下列开源图标（内联为 SVG path 数据，随 client.js 一起分发，不加载外部文件）。

- 来源：https://github.com/lucide-icons/lucide
- 版本：lucide-static 0.460.0
- 用途：分类图标的「电商·线 / 新媒体·线 / 运营客服·线 / 通用·线」四组，共 76 个图标
